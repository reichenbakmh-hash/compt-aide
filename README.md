# Compt’Aide

Application d’apprentissage de la comptabilité française.

Site statique : un seul fichier `index.html`, sans installation ni serveur.

Données du plan comptable général : ANC, version 2026, jeu de données ouvert CC0 (dépôt PC).

## Hébergement gratuit sur Cloudflare Pages

Workers & Pages > Create > Pages > Connect to Git, choisir ce dépôt. Framework : None. Build command : vide. Build output directory : `/`.

## Version 2

Atelier pratique (menu Pratique) : facturation avec écriture automatique, saisie d'écritures contrôlée, balance et résultat, estimation de TVA (CA3), journal et export FEC (18 colonnes, norme DGFiP). Données conservées dans le navigateur (stockage local).

## Version 3

Inscription avec accord de confidentialité, contact WhatsApp, et dans l'atelier pratique : grand livre, bilan et compte de résultat, plan d'amortissement, contrôles de cohérence. La base Cloudflare D1 reste à brancher : le texte de l'accord doit être relu avant mise en ligne.

## Version 4

Parcours en 6 niveaux, tableau de bord réel (écritures, résultat, TVA, progression), leçons 11 à 15, cas 5 à 9, glossaire, fiche métier avec questions d'entretien. L'accord de confidentialité s'ouvre par un lien souligné dans l'inscription.
